# Berea Health Notes - AI Clinical Note Helper

AI helper for nurses at Berea, Lesotho to write clear, structured clinical notes.

**Live App:** https://lcs-berea-notes-4368.ai.studio

**What it does:**
- Turns quick nurse notes into structured SOAP notes
- Flags urgent symptoms for follow-up
- Works in plain English for busy clinics

Built with Google AI Studio.
