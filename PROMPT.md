# Prompt Used to Build This App

I built this app in Google AI Studio with this instruction:

> Build a simple, fast web app for nurses at Berea Hospital, Lesotho.
> The nurse types quick, messy notes. The app turns them into a clear, structured SOAP note (Subjective, Objective, Assessment, Plan).
> Use plain, simple English. Highlight urgent symptoms in red for follow-up.
> Make it work well on a phone, for a busy clinic with low internet.
> Add a button to copy the final note.

## Why this prompt?
- Nurses are busy, they need speed
- SOAP is the standard format clinics use
- Plain English avoids confusion
- Mobile-first because most nurses use phones
